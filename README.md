## 🌐 Deployment

This portfolio is designed for deployment through **Netlify**, with the source code maintained on GitHub.

For a static HTML, CSS, and JavaScript website:

1. Import this repository into Netlify.
2. Leave the build command empty if no build process is required.
3. Set the publish directory to the folder containing `index.html`.
4. Deploy the website.

Future commits to the connected branch can trigger automatic redeployment.
